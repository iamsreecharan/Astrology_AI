These unmodified Noto Sans fonts are bundled for offline English PDF reports and names in supported scripts. They come from the Debian fonts-noto-core 20201225-2 package installed in the development image; upstream is https://github.com/notofonts/noto-fonts. See OFL.txt for the copyright notice and SIL Open Font License 1.1. Fonts are embedded as subsets in generated reports. Unsupported characters are written as explicit U+ code points instead of silently losing a name.
